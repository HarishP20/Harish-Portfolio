# Harish P — Personal Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Home, About, Skills, Projects, Education, and Contact sections
- Responsive layout for desktop, tablet, and mobile
- Lightweight hover effects and scroll-reveal animations
- Google Fonts and Font Awesome icons

## Files
- `index.html` — the portfolio website
- `Hari.jpeg` — optional profile photo used by the page

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then click **Save**.
5. Wait for deployment and open the URL shown in the Pages section.

## Important notes
- The HTML currently refers to a profile image named `Hari.jpeg`. Upload your image with that exact filename to the repository root, or update the image path in `index.html`.
- Replace placeholder social/project links (`href="#"`) with your real links.
- The contact form currently shows a local “Message Ready” confirmation; it does not send email or store submissions by itself.
- Review the contact details in the page before publishing it publicly.
